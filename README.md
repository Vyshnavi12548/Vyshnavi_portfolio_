## Run locally

No build step or package install is required. Open `index.html` in a browser, or serve this directory with a local static server:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000`.

## Publish with GitHub Pages

1. Create a new public repository named `Vyshnavi_portfolio` (or use a new repository name of your choice).
2. Upload the **contents of this folder** to the repository root. Keep `index.html`, `styles.css`, `script.js`, `assets/` and `resumes/` at the same level.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**, choose `main` and `/(root)`, then save.
5. Wait for the Pages deployment to complete. GitHub will show the published URL in the Pages settings.
